# SlayTheCircle · 组织视觉资产

## 主头像

[avatar.png](avatar.png) 为本轮选定的组织头像，1254 × 1254 像素，PNG / RGB，不透明背景。

[avatar-upload.jpg](avatar-upload.jpg) 是同一幅图的上传用 JPEG 导出，保持原尺寸与构图，去除元数据并使用质量 95 编码，文件小于 1 MB。组织设置中优先选择这一版；PNG 保留为原图。

设计思路由 SkuldMirror 提出：“STS2 的未掘宝石，然后给宝石 P 成原石”。通过内置 imagegen 工具，以《杀戮尖塔 2》未掘宝石（Hidden Gem）卡面和《原神》原石（Primogem）图标为参考生成候选。最终选择 A、B 两版之间的比例：保留深色岩堆、青绿色岩面、赭黄背景与金色光环，主体改为蓝粉色四角原石。

参考来源：

- 未掘宝石：本机游戏 v0.111.0 的原版卡面；《杀戮尖塔 2》与相关美术归 Mega Crit 所有。
- 原石图标：[Alphr · How to Get Primogems in Genshin Impact](https://www.alphr.com/get-primogems-genshin-impact/)，原石及《原神》相关设计归 HoYoverse 所有。

本资产用于非官方、非营利同人组织展示。第三方角色、游戏与美术权利归对应权利人；本文件不授予其额外使用许可。

## 维护

生成候选与完整提示词留在本地 `output/imagegen/`，由根 `.gitignore` 排除。正式选定的资产单独复制到这里，保留原图，不提交整轮生成目录。

更新组织账户头像需要在 GitHub 设置中上传本文件，具体步骤见[组织维护说明](../../docs/organization.md#上传组织头像)。
