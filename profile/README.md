# SlayTheCircle

把提瓦特的角色带进尖塔。我们制作《杀戮尖塔 2》的非官方原神主题模组，也分享制作模组的工具与经验。

Unofficial Genshin Impact–themed mods for Slay the Spire 2, with tools and knowledge for fellow mod makers.

[游玩娜维娅](https://steamcommunity.com/sharedfiles/filedetails/?id=3810999936) · [浏览项目](https://github.com/orgs/SlayTheCircle/repositories) · [制作新模组](https://github.com/SlayTheCircle/STS2-Template) · [获取帮助](https://github.com/SlayTheCircle/.github/blob/main/SUPPORT.md)

## 我们的项目 / Projects

| 项目 | 简介 | 状态与入口 |
|---|---|---|
| [娜维娅 / Navia](https://github.com/SlayTheCircle/STS2-Navia) | 以装填、礼炮轰鸣、摩拉与支援构筑为主题的可玩角色 | 已发布 · [Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3810999936) · [最新发行](https://github.com/SlayTheCircle/STS2-Navia/releases/latest) |

Navia is released; Charlotte is in development with no public release yet. STS2-Template is a starting point for developers.

## 开始游玩 / Play

娜维娅推荐通过 Steam 工坊订阅安装，并一并订阅依赖 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295)。手动安装包可从[最新发行](https://github.com/SlayTheCircle/STS2-Navia/releases/latest)获取。

安装步骤、游戏兼容范围与依赖版本以各项目 README、发行说明和 STATUS 为准。开发中的源码仓库不代表已经提供完整可安装包。

Subscribe to Navia and RitsuLib on Steam Workshop, or use GitHub Releases for manual installation. Check the project's README and release notes for compatibility and installation requirements.

## 一起制作 / Contribute

欢迎带着测试反馈、玩法设计、翻译、代码、文档或有明确授权的美术与音频参与。

- **报告 Bug 或提出建议**：前往对应项目的 Issues，附上版本、环境和复现步骤。
- **讨论玩法与使用问题**：娜维娅可使用 [Discussions](https://github.com/SlayTheCircle/STS2-Navia/discussions) 或工坊评论区；其他项目按其 SUPPORT 指引参与。
- **提交贡献**：先阅读对应项目的 CONTRIBUTING；通用约定见[组织贡献指南](https://github.com/SlayTheCircle/.github/blob/main/CONTRIBUTING.md)。
- **开始自己的模组**：从 [STS2-Template](https://github.com/SlayTheCircle/STS2-Template) 派生新仓库。

Feedback, design, translations, code, documentation, and authorized artwork are welcome. Please use the relevant project's channels and contribution guidelines.

## 名字的由来 / The name

「圆」即「原」——借一个谐音向原神致意。至于尖塔为什么是圆的，我们也没有答案。

“Circle” nods to a Chinese homophone of “Genshin.” Why is the Spire round? We don't know either.
